3.3 元组

元组和列表类似，但属于不可变序列，元组一旦创建，用任何方法都不可以修改其元素。
元组的定义方式和列表相同，但定义时所有元素是放在一对圆括号“（）”中，而不是方括号中。

第 4 页 · 3.3.2 元组与列表的区别

3.3.2 元组与列表的区别

元组一旦定义就不允许更改。
元组没有append()、extend()和insert()等方法，无法向元组中添加元素。
元组没有remove()或pop()方法，也无法对元组元素（del()）进行删除操作，但是使用del可以删除元组对象。

第 5 页 · 3.3.2 元组与列表的区别

3.3.2 元组与列表的区别

元组的速度比列表更快。如果定义了一系列常量值，主要用途仅是对它进行遍历或者其他类似操作的话，那么一般使用元组而不用列表。
元组对不需要改变的数据进行“写保护”将使得代码更加安全。
元组可用作字典的“键”，也可以作为集合的元素。列表不能作为字典的“键”，包含列表、字典、集合或其他类型可变对象的元组也不能做字典的“键”。

第 6 页 · 3.3.2 元组与列表的区别

3.3.2 元组与列表的区别

虽然元组是不可变序列，如果元组中包含列表或其他类型的可变序列，这些对象是可变的，但元组元素的引用仍是不可变的。
>>> x = ([1, 2], 3)
>>> x[0][0] = 5
>>> x
([5, 2], 3)
>>> x[0].append(8)
>>> x
([5, 2, 8], 3)
>>> x[0] = x[0]+[10]
TypeError: 'tuple' object does not support item assignment
>>> x
([5, 2, 8], 3)
