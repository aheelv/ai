第 1 页 · 3.5 集合

3.5 集合

集合是无序、可变序列，使用一对大括号界定，元素不可重复，同一个集合中每个元素都是唯一的，由{ }引导。
集合中只能包含数字、字符串、元组等不可变类型（或者说可哈希）的数据，而不能包含列表、字典、集合等可变类型的数据。

使用set()将其他类型数据转换为集合
>>> a_set = set(range(8,14))
>>> a_set
{8, 9, 10, 11, 12, 13}
>>> b_set = set([0, 1, 2, 3, 0, 1, 2, 3, 7, 8]) #自动去除重复
>>> b_set
{0, 1, 2, 3, 7, 8}
>>> c_set = set() #空集合
>>> c_set
set()

第 3 页 · 3.5.1 集合的创建与删除

3.5.1 集合的创建与删除

使用del()删除整个集合。集合的pop()方法弹出并删除其中一个元素，remove()方法直接删除指定元素，clear()方法清空集合。
>>> a = {1, 4, 2, 3}
>>> a.pop()
1
>>> a.pop()
2
>>> a
{3, 4}
>>> a.add(2)
>>> a
{2, 3, 4}
>>> a.remove(3)
>>> a
{2, 4}

第 4 页 · 3.5.2 集合运算

3.5.2 集合运算

交集、并集、差集、对称差集等运算。
>>> a_set = set([8, 9, 10, 11, 12, 13])
>>> b_set = {0, 1, 2, 3, 7, 8}
>>> a_set | b_set #并集
{0, 1, 2, 3, 7, 8, 9, 10, 11, 12, 13}
>>> a_set & b_set #交集
{8}
>>> a_set - b_set #差集
{9, 10, 11, 12, 13}
>>> a_set ^ b_set #对称差集
{0, 1, 2, 3, 7, 9, 10, 11, 12, 13}

集合包含关系测试
>>> x = {1, 2, 3}
>>> y = {1, 2, 5}
>>> z = {1, 2, 3, 4}
>>> x < y #比较集合大小/包含关系
false
>>> x < z #真子集
true
>>> y < z
false
>>> {1, 2, 3} <= {1, 2, 3} #子集
true
