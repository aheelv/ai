📈 1. 线性回归

第 3 / 20 页

线性回归基础

线性回归用于预测连续的数值型目标变量。

公式

Y = β₀ + β₁X + ε

  • Y：因变量（预测目标）
  • X：自变量（特征）
  • β：回归系数

评估指标

  • R²：决定系数，越接近1越好
  • MAE：平均绝对误差
  • RMSE：均方根误差
from sklearn.linear_model import LinearRegression model = LinearRegression() model.fit(X_train, y_train)

📊 2. 逻辑回归

第 4 / 20 页

逻辑回归基础

逻辑回归用于二分类问题，输出概率值。

公式

P(Y=1) = 1 / (1 + e^(-z))

其中 z = β₀ + β₁X

应用场景

  • 用户流失预测
  • 购买意向预测
  • 信用风险评估
  • 营销响应预测

💡 优势

结果可解释，能输出概率，易于部署

⏰ 3. 时间序列分析

第 5 / 20 页

时间序列三要素

趋势 Trend

长期上升或下降的整体趋势

季节性 Seasonality

固定周期内的周期性波动

残差 Residuals

无法解释的随机波动

常用方法

  • 移动平均：简单平滑
  • 指数平滑：加权移动平均
  • ARIMA：自回归差分
  • Prophet：Facebook时序库
from prophet import Prophet model = Prophet(yearly_seasonality=True)

📉 4. 主成分分析 PCA

第 6 / 20 页

PCA原理

PCA通过线性变换，将高维数据投影到低维空间，同时保留最大方差。

核心思想

  • 找出数据中方差最大的方向
  • 用少数主成分代表原始数据
  • 去除冗余和噪声

应用场景

  • 降维：减少特征数量
  • 可视化：2D/3D展示高维数据
  • 去噪：去除不重要的信息
  • 特征提取：生成新的组合特征
from sklearn.decomposition import PCA pca = PCA(n_components=2) X_pca = pca.fit_transform(X)

🎯 5. 聚类分析

第 7 / 20 页

聚类分析概述

聚类是将相似样本分到同一组的无监督学习方法。

主要算法

  • K-Means：基于距离的划分
  • 层次聚类：构建树状结构
  • DBSCAN：密度聚类

K-Means流程

  • 1. 选择K个初始中心
  • 2. 计算距离，分配样本
  • 3. 重新计算中心
  • 4. 重复直到收敛
from sklearn.cluster import KMeans kmeans = KMeans(n_clusters=5) labels = kmeans.fit_predict(X)
